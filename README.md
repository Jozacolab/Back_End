# Sistema de Gerenciamento de Produtos - Back-end Java

Aplicação de console desenvolvida em Java para gerenciamento de produtos (CRUD em memória), demonstrando o uso de Orientação a Objetos, Tratamento de Exceções e Coleções.

## 🛠️ Pré-requisitos
- Java Development Kit (JDK) 17 ou superior instalado.

## 🚀 Como Compilar e Executar

### 1. Compilação
Abra o terminal/PowerShell na pasta raiz do projeto (`Back_End`) e execute:

```powershell
javac -encoding utf-8 -d bin -sourcepath src src\br\com\faculdade\Main.java

```Comando para compilar
& "C:\Program Files\Java\jdk-17\bin\javac.exe" -encoding utf-8 -d bin -sourcepath src src\br\com\faculdade\Main.java

```Comando para executar a aplicação no terminal
java -cp bin br.com.faculdade.Main
